# RecoHR — mô phỏng

Thư mục chứa các màn mô phỏng (HTML/JS tĩnh) dành riêng cho RecoHR.

Xem trực tiếp: https://dungnt1702.github.io/reco-demo/recohr/

## Quy ước

- Mỗi màn là một tệp `.html` trong thư mục này (hoặc trong thư mục con theo giai đoạn, ví dụ `gd01/`).
- Chỉ dùng đường dẫn tương đối. GitHub Pages phục vụ repo dưới `/reco-demo/`, nên đường dẫn tuyệt đối dạng `/assets/...` sẽ hỏng.
- Hiện đang dùng tạm giao diện chung `../sales-hub/assets/reco.css`. Khi HR cần giao diện riêng, tạo `recohr/assets/` và chuyển sang dùng nó.
- Thêm màn mới vào danh sách trong `index.html` của thư mục này.
